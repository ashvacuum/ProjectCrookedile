# Aspirational screen prompts

> **Kind:** Reference · **Status:** Draft · **Updated:** 2026-11-07
>
> **Summary:** Image prompts for the target look of six more screens, each built on the G1 battle reference.
>
> **Source of truth:** this doc · **Related:** [`art-bible.md`](../art-bible.md) · [`ui-look-prompts.md`](ui-look-prompts.md) · [`battle-ui-mock-prompt.md`](battle-ui-mock-prompt.md)

The battle screen's target look is [`crookedile-style-g1.webp`](../design/crookedile-style-g1.webp). These prompts take
that look to the rest of the game, one screen each, so the beta UI (the Crookedile UI Screens canvas) has a target to
grow into. Screen IDs match the UI spec's Screen catalogue.

**How to use them:** attach `docs/design/crookedile-style-g1.webp` as the style reference for every generation, paste
one whole block, and generate at 16:9. Save results beside this file as `aspire-<screen>-1.png` and add a line under
the screen's Notes. Each block repeats the style lines so it can be pasted alone.

**Every block carries two fixes** from the art bible's known misses: every character is an anthropomorphic animal, and
signs carry short slogans, never the prompt's describing words.

---

## F6 Main menu

```text
A 16:9 video game main menu, matching the attached image's style exactly: hand-drawn 2D, confident thick ink
outlines with varied weight, characters drawn like an animated cartoon with strong expressive acting, softly
painted backgrounds with visible brushwork, warm lighting, rich but slightly muted mustard, teal, brick red,
cream and olive. Every character is an anthropomorphic animal.

Scene: the right two thirds show a heavy-set older crocodile politician in a plain barong on a campaign stage at
dusk, waving to an unseen crowd, his face a practised deadpan smile; behind him a huge painted campaign
tarpaulin with his own portrait and the slogan "TAPAT. TOTOO." in hand-lettered type; strings of bulb lights.
Left third, a cream panel with dark ink outlines holding the game title "CROOKEDILE" in a bold hand-lettered
poster face, and a menu in one bold condensed sans-serif: a large mustard "CONTINUE" button with a small line
"Faith Leader · Day 3 · 72 Credibility" under it, then NEW RUN, COLLECTION, STATS, SETTINGS, QUIT as plain cream
buttons. A small profile tag in the bottom left: "CANDIDATE 1".

NOT photoreal, NOT 3D, NOT anime, NOT flat vector, NOT grimdark.
```
